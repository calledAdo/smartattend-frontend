# Face model assets

These are the `tiny_face_detector`, `face_landmark_68`, and `face_recognition` model manifests and shards from the [face-api.js repository](https://github.com/justadudewhohacks/face-api.js/tree/master/weights), retrieved on 2026-10-06. face-api.js is MIT licensed.

The app serves these files locally. Enrollment and check-in must use this same model set; replacing any model requires verifying that new descriptors remain compatible with stored templates and the backend comparison threshold.
